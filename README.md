# Grocery Shopping Console Application
A Java console application that simulates a simple grocery shopping experience.

## Features
- Search for grocery items
- Add items to a shopping cart
- Calculate the total bill
- Custom exception handling for unavailable items
- Item price calculations

## Technologies Used
- Java 21
- VS Code
- Ubuntu (Wsl)
- Git

## Concepts Practiced
- Java Fundamentals
- Arrays
- Methods
- Exception Handling
- Loops and Conditional Statements
- User Input (Scanner)

## Future Improvements
- Applying discounts
- Add inventory management
- Filter items below a chosen price
- Print a detailed shopping receipt
